01 · Introduction

What is Linear Regression?

Linear Regression is a supervised machine learning algorithm used to predict a continuous numerical value. It learns the relationship between an input variable (X) and an output variable (Y) by fitting a straight line to observed data.

🎯

Objective

Predict numerical outcomes and understand how the input variable relates to the output.

📚

Learning Type

Supervised learning: the model learns from examples with known inputs and outputs.

🏡

Simple Example

Estimate a house price using its size, or estimate marks using study hours.

02 · Mathematical Concept

The Linear Regression Formula

The model represents the relationship using a straight-line equation:

Ŷ = b₀ + b₁XŶ = predicted output · X = input · b₀ = intercept · b₁ = slope

Intercept (b₀)

The predicted value of Y when X is zero, where that interpretation makes sense.

Slope (b₁)

The expected change in predicted Y for a one-unit increase in X.

Best-fit line

Ordinary least squares chooses coefficients that minimize the sum of squared residuals.

03 · How It Works

From data to prediction

Step 1 — Collect data

Gather examples such as study hours and students' marks.

Step 2 — Prepare data

Check missing values, errors and whether the variables are suitable.

Step 3 — Train the model

The algorithm estimates the line's slope and intercept from training data.

Step 4 — Make predictions

Use the fitted equation to estimate an output for a new input.

Step 5 — Evaluate

Compare predictions with actual values using metrics such as MAE, RMSE or R².

06 · Evaluation

Advantages and limitations

💚 Advantages

  • Easy to understand and explain.
  • Fast to train on many suitable datasets.
  • Shows the direction and size of a linear relationship.

💜 Limitations

  • May perform poorly for complex non-linear relationships.
  • Can be sensitive to outliers.
  • Results depend on data quality and assumptions.

🔎 Remember

A relationship does not automatically prove causation. Always evaluate the model on data not used for training.

08 · Conclusion

What have we learned?

Linear Regression is a foundational supervised learning technique that models a linear relationship between input and output variables. It uses a best-fit line to estimate numerical outcomes and is widely used for prediction and trend analysis.

In this blog, we explored its objective, equation, working steps, practical applications, strengths and limitations. The interactive example demonstrated how an input can change a predicted value. In real projects, predictions should be tested against actual data before being relied upon.

Key takeaway: Linear Regression helps us understand patterns in data and make informed numerical predictions.
