LET'S START HERE

01. Introduction ✿

Imagine you know the size of a house and want to estimate its price. Or you know how many hours a student studies and want to estimate their marks. Linear Regression helps us make these kinds of predictions by learning the relationship between variables.

💡
The idea in one line

Use existing data to find a straight line that best describes a relationship, then use that line to predict a new value.

THE BASICS

02. What is Linear Regression?

Linear Regression is a supervised machine learning algorithm used to predict a continuous numerical value. It studies how an output (the target) changes when one or more inputs (features) change.

📥

Input / Feature (X)

The information we know, such as house area or study hours.

🎯

Output / Target (Y)

The number we want to estimate, such as price or exam marks.

Think of it as drawing the most useful straight line through a cloud of dots.

TWO COMMON TYPES

03. Types of Linear Regression

A

Simple Linear Regression

Uses one input feature to predict an output.

Example: area → house price
B

Multiple Linear Regression

Uses two or more input features to predict an output.

Example: area + rooms → price
FROM DATA TO PREDICTION

04. How does it work?

1
Collect the data

Gather examples with known inputs and outputs.

2
Fit the best line

The algorithm finds a line that stays close to the observed points.

3
Measure the errors

Compare predicted values with actual values and reduce the overall error.

4
Predict a new value

Enter a new input and use the learned line to estimate its output.

A LITTLE MATH

05. The formula

SIMPLE LINEAR REGRESSION
ŷ = b₀ + b₁x

Predicted output = intercept + (slope × input)

ŷ

Predicted value
The output estimated by the model.

b₀

Intercept
The predicted value when x is zero.

b₁

Slope
How much the prediction changes when x increases by one unit.

x

Input feature
The value supplied to the model.

The model commonly chooses its line by minimising the sum of squared differences between actual and predicted values. This is called Ordinary Least Squares (OLS).

A BALANCED VIEW

07. Benefits & limitations

✓ Why it is useful

  • Easy to understand and explain
  • Fast to train on many datasets
  • Shows how inputs relate to an output
  • Provides a useful baseline model

! What to watch out for

  • Assumes a linear relationship
  • Outliers can affect the fitted line
  • Missing or poor-quality data can mislead
  • Prediction is not proof of causation
